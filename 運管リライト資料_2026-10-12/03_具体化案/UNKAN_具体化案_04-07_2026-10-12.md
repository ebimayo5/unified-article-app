## 04 実務上の知識及び能力(事故報告・点呼・運行管理)
既存の本文で、事故報告の期限・速報の条件は確認済み。追加案:
| 追加する内容 | 根拠 |
|---|---|
| 点呼の「記録」は、運転者等ごとに、点呼を行った旨・報告・確認・指示の内容に加え、点呼を行った者と受けた者の氏名、事業用自動車の識別表示、点呼の日時・方法などを記録し、**1年間保存** | 貨物自動車運送事業輸送安全規則 第7条第5項 |
| 乗務前点呼の確認事項は、酒気帯び、疾病・疲労・睡眠不足等、道路運送車両法第47条の2による点検の実施または確認(運転者に対して) | 同 第7条第1項 |
| 乗務後点呼は、事業用自動車・道路・運行の状況の報告と、運転者の酒気帯びの有無の確認。交替した運転者がいる場合は、その交替運転者への通告についても報告を求める | 同 第7条第2項 |
| 事故の記録は、乗務員等の氏名・事故の発生日時と場所・概要などを、運行を管理する営業所で**3年間保存** | 同 第9条の2 |
| 運行記録計の記録は**1年間保存**。対象は、車両総重量7トン以上**または**最大積載量4トン以上の普通自動車(ほか、けん引自動車・特別積合せの運行系統) | 同 第9条(本文08に同じ内容あり) |

## 05 労働基準法関係(+改善基準告示)
既存の本文は制度の区別が中心。追加案(労基法の本文で確認済み):
| 追加する内容 | 根拠 |
|---|---|
| 法定労働時間は、休憩時間を除き**1週間40時間**、1日**8時間** | 労働基準法 第32条第1項・第2項 |
| 休憩は、労働時間が**6時間を超える**場合に少なくとも**45分**、**8時間を超える**場合に少なくとも**1時間**。労働時間の途中に与える。原則一斉に与える(労使協定の例外あり) | 同 第34条 |
| 休日は**毎週少なくとも1回**(4週間を通じ4日以上の休日を与える場合は例外) | 同 第35条 |
| 割増賃金の率は、時間外・休日の労働について、通常の賃金の計算額の**2割5分以上5割以下**の範囲で政令が定める率以上 | 同 第37条第1項(具体的な率は政令) |
| 年次有給休暇は、雇入れから**6か月**継続勤務し、全労働日の**8割以上**出勤した労働者に**10労働日** | 同 第39条第1項 |
| 36協定は、過半数労働組合または過半数代表者との**書面**による協定を、行政官庁に届け出る | 同 第36条第1項 |
| 自動車運転の業務には、第36条第5項の時間外労働の上限について**当分の間の特例**がある(貨物自動車運送事業を含む) | 同 第140条 |

注: 改善基準告示の拘束時間・休息期間・運転時間の具体値は、厚労省のトラック向け公式PDFの該当ページ(ページ3の定義、5〜10ページ)を、本文に入れる直前に取り直して確認する(今回は条文ではなく告示のため、このファイルでは確定させていない)。

## 06 道路交通法関係
既存の本文には具体的な距離・時期がほぼない。追加案(道交法の本文で確認済み):
| 追加する内容 | 根拠 |
|---|---|
| **駐停車禁止**: 交差点・横断歩道・自転車横断帯・踏切・軌道敷内・坂の頂上付近・勾配の急な坂・トンネル。交差点の側端または曲がり角から**5メートル以内**。横断歩道・自転車横断帯の前後の側端から**5メートル以内** | 道路交通法 第44条第1項第1〜3号 |
| 安全地帯の左側部分と、その前後の側端から**10メートル以内**。乗合自動車の停留所の標示柱等から**10メートル以内**。踏切の前後の側端から**10メートル以内** | 同 第44条第1項第4〜6号 |
| **駐車禁止**: 道路工事の区域の側端から**5メートル以内**。消防用機械器具の置場・防火水槽の側端や出入口から**5メートル以内**。消火栓・指定消防水利の標識の位置などから**5メートル以内**。火災報知機から**1メートル以内** | 同 第45条第1項第2〜5号 |
| 駐車により車両の右側の道路上の余地が**3.5メートル**未満となる場所での駐車の禁止(貨物の積卸しで運転者が離れない場合などは例外) | 同 第45条第2項 |
| **積載の制限**(長さ): 自動車の長さ+その長さの**10分の2**まで。(幅): 自動車の幅+その幅の**10分の2**まで。(高さ): **3.8メートル**から積載する場所の高さを減じたもの(普通自動車の区分や公安委員会の定めで異なる) | 道路交通法施行令 第22条第3号 |
| 積載物は、車体の**前後から自動車の長さの10分の1**を超えてはみ出さない。左右は幅の10分の1まで(詳細は同条) | 同 第22条第4号 |

注: 最高速度・追越し・徐行の具体的な数値は、本文に入れる前に、該当条文または公安委員会の規制として別途確認する(未確認のため載せない)。

## 07 道路運送車両法関係
既存の本文は制度の区別が中心。追加案(車両法・規則の本文で確認済み):
| 追加する内容 | 根拠 |
|---|---|
| **検査証の有効期間**: 旅客運送・貨物運送の用に供する自動車(検査対象軽自動車を除く)は**1年**、その他は2年 | 道路運送車両法 第61条第1項 |
| **初めて検査証を交付する場合**: 貨物運送用で車両総重量**8トン未満**の自動車は**2年** | 同 第61条第2項第1号 |
| 有効期間の**起算日**: 有効期間が満了する日の**2か月前**から満了日までの間に継続検査を受け有効期間を記録する場合は、満了日の**翌日** | 道路運送車両法施行規則 第44条第1項ただし書 |
| **日常点検**: 自動車の使用者は、走行距離・運行時の状態等から判断した適切な時期に、目視等で点検する。**一定の自動車(事業用自動車など、第48条第1項第1号・第2号の自動車)**は**1日1回、運行の開始前**に点検する | 同法 第47条の2第1項・第2項 |
| **定期点検整備**: 自動車運送事業の用に供する自動車などは**3か月ごと**、第2号の自家用自動車などは6か月ごと、その他は**1年ごと** | 同法 第48条第1項 |

注: 保安基準の個別の寸法・性能値は、本文に入れる前に、保安基準の該当条を取り直して確認する(未確認のため載せない)。
